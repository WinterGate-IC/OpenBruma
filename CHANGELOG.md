# Changelog

## [0.1.0] - unreleased

### Added
- Initial OpenBruma repository scaffold.
- archiso profile skeleton.
- XFCE desktop package list.
- linux-lts kernel selection.
- Calamares / archinstall installer configuration.
- UEFI + BIOS boot entries.
- Branding assets placeholders.
- Build scripts for host (VirtualBox) and guest (Arch).
- Documentation: BUILD, VM-SETUP, TESTING, LICENSES, REPRODUCIBILITY.

### Known limitations
- Arch edition is x86_64 only; no 32-bit support.
- Calamares may not be available in early iterations; archinstall is the
  fallback installer.
- Low-RAM profile documented but not yet performance-tuned.
